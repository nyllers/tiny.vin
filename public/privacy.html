Privacy Policy

tiny.vin is a small, personal URL-shortening tool. This page explains what data it collects and why.

Tiny URLs

When you submit a URL to shorten, we store that URL together with the generated short code so that visiting the tiny URL can redirect to it.

Account information

Signing in with Google is required to create tiny URLs. When you sign in, we store the email address and display name Google gives us, along with which provider you used, so we can recognize your account.

Login activity

Each time you sign in, we record the timestamp and the IP address the request came from, for security and abuse monitoring.

How this data is used

This data is used solely to operate tiny.vin: creating and redirecting tiny URLs, and restricting URL creation to signed-in accounts. We do not sell, share, or use this data for advertising.

Where it's stored

Data is stored in Cloudflare D1, the database used to host this service.

Android and iOS apps

The tiny.vin apps talk to the same API described above and store nothing beyond what's needed to do that: your API key, kept on-device in encrypted storage (Android's EncryptedSharedPreferences / iOS Keychain) and never sent anywhere except to tiny.vin itself. Shortening a link copies the result to your clipboard and shows a local notification, both handled entirely on-device.
